# Classification matrix

> Compass every page **and its sections**. Report type + confidence + evidence. Flag mixed pages with a proposed per-section split — don't split mechanically.

**Confidence key:** H = clear signals on both compass axes · M = one axis unclear · L = weak/conflicting → flag for human judgment.
**Evidence examples:** imperative verbs, goal-oriented heading, first-person plural, lookup table, "why" reasoning, assumed competence, parameter tables.
